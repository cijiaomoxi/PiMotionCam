# PiKrellCam → PiMotionCam 2.8.2 · 功能对照 / Feature comparison

参考 [billw2/pikrellcam](https://github.com/billw2/pikrellcam) master 提交 `994384dae9d01d6210518ce6515ecd011b32d38f`（2020-06-08），重点核对 `config.c`、`motion.c`、`display.c`、`audio.c`、`preset.c`、`servo.c`、`event.c`、`sunriset.c`、`multicast.c`、`tcpserver.c` 及网页帮助。独立实现功能，不复制上游 GPL 源码。

Reference: upstream master commit above, checked against configuration, motion, display, audio, preset, servo, event, solar, multicast/TCP and web help. Functionality is independently implemented rather than copied from GPL source.

旧版报告的“约 96 项 / 53%”不是严格一致的计量口径，现删除该百分比。**代码实现与实机验证是两回事**：下表描述代码能力，验证进度见 [记录](V2.8.2-VALIDATION.md)。

The previous approximate “96 features / 53%” used inconsistent counting and has been removed. This table describes implementation; completed hardware tests are listed separately in the [validation record](V2.8.2-VALIDATION.md).

| 功能 / Capability | 2.8.2 实现 / Implementation | 差异 / Differences |
| --- | --- | --- |
| CSI、USB、预览、区域、双算法 / Cameras, preview, regions, dual detection | 保留已有能力 / Retained | libcamera / picamera2、rpicam、V4L2，使用现代系统 |
| 硬件运动矢量 / Hardware motion vectors | 软件替代 / Software alternative | **不提供 MMAL**；稀疏块匹配方向与矢量、方向过滤、大面积运动确认、噪点统计，不能视为硬件等价输出 |
| 确认间隔、去噪 / Confirmation and noise | 连续帧检测 + 可选 burst 窗口 / Consecutive frames plus optional burst window | 参数和统计定义不同；burst 尊重启用区域 |
| CSV、检测 FIFO、事件文件 / CSV, FIFO, event log | 新增 / Added | 有界后台队列、非阻塞 FIFO、轮转 CSV / JSONL，文件格式不同 |
| 旋转、镜像 / Rotation, mirror | CSI 保留，USB 新增 / CSI retained, USB added | USB 变换需要重编码，90°/270° 交换输出尺寸 |
| 裁剪、软件防抖、效果 / Crop, stabilization, effects | 新增 / Added | 可选软件处理；21 个命名预设，部分共享算法；非 MMAL 精确复现 |
| 曝光、测光、白平衡 / Exposure, metering, white balance | 保留已有矩阵 / Retained | 支持取决于相机；不提供旧 MMAL 的全部 13 个命名曝光模式，可用现代自动 / 手动参数 |
| 独立尺寸抓拍 / Separate still resolution | 新增 / Added | 临时停止当前视频采集；尺寸须由设备支持，不是上游不中断采集的实现 |
| 手动、外部触发 / Manual and external trigger | 新增真正立即录制 / Immediate recording added | 纠正旧报告：`record on` 原来只是解除暂停；新命令 `record start/stop` 控制手动录像 |
| 预录、补录、循环、延时 / Pre/post-roll, loop, timelapse | 保留 / Retained | 事件与循环共用编码器，事件优先 |
| 运动抓拍、命名、序号 / Motion photos, names, sequence | 新增 / Added | 持久化文件锁序号、安全文件名模板 |
| 缩略图维护 / Thumbnail repair | 新增整帧补建 / Full-frame repair added | 无历史检测框时不能重建旧目标裁剪图 |
| 音轨与实时监听 / Recorded and live audio | 音轨保留，监听新增 / Retained and added | 同一 ALSA 读取者；浏览器 PCM 单向监听，非 WebRTC / 双向对讲 |
| 增益、声音触发、MP3 / Gain, sound trigger, MP3 | 新增 / Added | 软件增益；声音触发尊重录像暂停；独立 MP3 共用采集 |
| 字幕、信息、音量条 / Captions, information, meter | 新增 / Added | 可选烧入；检测读取烧字之前的画面 |
| OSD 菜单 / OSD menu | 三项快捷菜单及网页设置 / Three-action menu plus web settings | **不复刻完整的上游菜单树**；主要参数通过双语网页设置 |
| 外观、扩展链接 / Theme and links | 新增 / Added | 深 / 浅 / 系统主题、HTTP(S) 链接 |
| 配置预设复制移动 / Preset transfer | 新增 / Added | 全预设或单一配置部分；激活后检测静置 |
| 舵机 / Servo | 增补 / Extended | 反相、步进、多步、巡航、绑定预设；补上 lgpio 实际输出，需硬件权限与接线 |
| 日出日落调度 / Solar schedules | 新增 / Added | NOAA 近似计算、民用晨昏、分钟偏移，极昼夜跳过缺失事件 |
| 事件钩子 / Hooks | 增补六种 / Six added | 原有钩子保留；多机消息通过环境变量传递 |
| TCP、组播、ACK、去重 / TCP, multicast, ACK, deduplication | 新增签名协议 / Signed protocol added | 默认关闭、密钥和来源白名单；**不兼容旧未认证原始包** |
| 媒体与归档空间 / Storage and archive guards | 保留并扩展 / Retained and extended | 本地 / 已挂载 NFS、SMB 日历归档；复制校验、剩余空间与挂载点检查；SSH 沿用 SCP |
| 开机 NFS 挂载 / NFS boot mount | 操作系统负责 / Managed by the OS | 应用不执行 root 挂载；用系统挂载配置自动挂载后再启动服务 |
| 日志、CLI、相机配置 / Log, CLI, camera profile | 新增 / Added | 行数可设、CLI 配置 / 控制 / 校验、相机设置导入导出 |
| 双语、密码、更新回退 / Languages, password, upgrade/rollback | 保留 / Retained | PiMotionCam 中英文；保留旧服务与共享数据路径 |

用户已选择保留 Debian 13 / aarch64，采用软件方向分析。树莓派[官方相机文档](https://www.raspberrypi.com/documentation/accessories/camera-software.html)将旧相机栈标为不再支持；本版本不降级或重装系统来恢复 MMAL。

The user selected the current Debian 13 / aarch64 system with software analysis. [Raspberry Pi’s documentation](https://www.raspberrypi.com/documentation/accessories/camera-software.html) marks the legacy camera stack unsupported. This release does not downgrade the OS to recover MMAL.
