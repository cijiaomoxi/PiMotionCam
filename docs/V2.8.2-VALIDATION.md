## 2.78 实机已完成 / Completed on 2.78

- USB 修复：重新接线和独立供电后，系统识别 Realtek USB Camera，以及独立 USB 麦克风和摄像头麦克风；过流后的新枚举已确认。
- 在真实 V4L2 `/dev/video1` 上检查 0/90/180/270° × none/horizontal/vertical/both 全部 16 组合。实际 JPEG 尺寸与预期一致。具体像素方向另外通过合成四色图的 ffmpeg 端到端校验。
- 两个实际麦克风均输出 16 kHz PCM，停止监听后客户端数归零且采集释放；分别录制出约 1.98 秒、ffprobe 可解码的 MP3。
- 自动录像暂停时，成功录制约 3.1 秒 H.264 + AAC 手动视频；音轨确认存在。声音触发生成 `algorithm=audio` 事件。未进行声画同步的实验室延迟测量。
- CSI OV5647 成功独立抓拍 **2592×1944**，完成后恢复 **1280×720 / 10 fps** 实时预览。
- Pi 上完整新增测试 **33/33 通过**，包括实际 TCP 连接；其后补充两个相机节点选择用例，本地最终套件为 35 项（离线重跑跳过 TCP 1 项）。
- 实际浏览器中英页面验证及真实麦克风点击播放 / 停止通过；合成浏览器数据另作补充，不混同硬件结果。
- 原设置按部署前备份恢复：**中文 zh-CN、CSI 索引 0、自动录像暂停、音频与实时监听关闭、原区域及参数**。早先记录中的英文偏好与本次备份不一致，本次以实际备份为准。
- 升级 / 回退验证：2.8.1 → 2.8.2 两次重启后均恢复正常采集，最终保持 2.8.2。

Both real microphones passed streaming/release/MP3 checks. All 16 USB transform combinations produced the expected JPEG dimensions, with independent synthetic pixel-direction checks. Manual H.264/AAC, real sound-triggered events and a 2592×1944 CSI still succeeded. The original Chinese/CSI/paused/audio-off configuration was restored. Upgrade/rollback recovered capture. Laboratory A/V latency measurements were not performed.
