# PiMotionCam 2.8.2 · 新功能 / New features

[中文首页](../README.zh-CN.md) · [English home](../README.en.md) · [验证状态 / Validation](V2.8.2-VALIDATION.md)

本页说明新增操作；原有预览、区域编辑、事件 / 循环录像、延时摄影、外部存储、密码保护和升级方式继续保留。新增能力默认关闭或保持原行为，不需要降级系统。

This page covers the new controls. Existing preview, region editing, event/loop recording, timelapse, storage, password and upgrade workflows remain available. Optional features start disabled or retain existing behavior. No OS downgrade is required.

## 实时音频 / Live audio

1. 接入 USB 摄像头麦克风、USB 麦克风或可采集音频的声卡。在树莓派上用 `arecord -l` 确认识别；普通输出声卡不提供采集能力。
2. 在“媒体 → 音频”选择设备，勾选“允许浏览器实时监听”，保存，再点击“监听声音”。预览页也有监听与停止按钮。浏览器要求用户点击才能播放。
3. “监听音量”只影响当前浏览器；“麦克风增益”在服务器对 PCM 应用 -30 至 +30 dB 增益，会影响监听、声音检测与录音。过大增益会削波。
4. “给录像加声音”单独决定是否给事件 / 循环录像加入 AAC 音轨；仅监听不会打开这个开关。

Connect a capture-capable USB camera microphone, USB microphone or sound card and check `arecord -l`. On Media → Audio, select the device, enable browser listening, save and click Listen live. A user gesture is required for playback. Browser volume is local; server gain affects monitoring, detection and audio recording. Video audio remains a separate option.

通过同源 HTTP 传输 S16_LE PCM，浏览器使用 AudioContext 播放，局域网 HTTP 无需 AudioWorklet。采集与录像共用一个 ALSA 读取进程，最多四个监听客户端；慢客户端跳过旧数据，停止后释放监听引用。16 kHz 单声道的原始音频约 32 KB/s，每个客户端各占一份传输带宽。无回声消除、双向对讲或 WebRTC 音视频同步；视频与实时音频是独立通路。

Uses same-origin S16_LE PCM and AudioContext, including LAN HTTP without AudioWorklet. One ALSA reader serves recording and up to four listeners. Slow listeners skip old data; stopping releases their capture lease. At 16 kHz mono, each listener receives about 32 KB/s. This is one-way monitoring, without echo cancellation, talkback or WebRTC A/V synchronization.

在同一面板可以启用“声音触发录像”，设置触发电平及持续时间；自动录像暂停时不会被声音触发。电平采用原有 -60 至 0 dB 映射到 0–1 的表值。还可以独立开始 / 停止 MP3 录制，最长一小时；文件列在“独立音频文件”中。音频录制失败不会破坏已有视频。

The same panel provides sound triggers with a level and hold time. Paused automatic recording suppresses these triggers. The level uses the existing -60…0 dB meter mapped to 0…1. Audio-only MP3 recording can run for up to one hour; Browse lists the files. Audio failures leave existing video intact.

## 画面与运动分析 / Image and motion analysis

- 原来的旋转 / 镜像设置现在也作用于 USB MJPEG。正角度沿用原始 CSI 路径的逆时针约定；90° / 270° 会交换输出宽高。变换后的帧统一供预览、检测、抓拍与录像使用。无变换且摄像头输出 MJPEG 时继续直接复制压缩帧。
- “侦测调参 → 软件运动分析”可启用稀疏块匹配方向、矢量箭头、指定方向触发、大面积运动确认和容许间隔。大面积运动尊重启用的检测区域。方向不明确时，指定方向过滤不会触发。它不是目标跟踪，也不是 MMAL 硬件矢量。
- 可保存每秒 CSV、运动开始 / 结束 JSONL 和本机 FIFO 检测输出。文件在共享 `logs/`，单文件超过 5 MB 时保留一个轮转副本。FIFO 无读取者时不会堵塞采集。
- 云台移动、预设切换后可设置短暂停止检测，避免将相机移动误判为目标移动。
- “画面处理”提供任意归一化裁剪、21 个命名软件效果预设及轻微平移防抖。效果为独立实现，部分预设共享处理算法，不宣称与旧 MMAL 逐像素相同。防抖裁去约 3% 边缘，仅适合轻微抖动。
- 可把时间、自定义文字、帧 / 检测信息和音量条烧入预览与录像。检测读取烧字之前的帧，字幕本身不会触发运动。开启这些处理会增加 CPU 及 JPEG 重编码损耗。

Rotation/mirroring now applies to USB MJPEG, with counterclockwise positive angles and swapped output dimensions at 90°/270°. Untransformed native MJPEG stays passthrough. Software analysis offers sparse block matching, vectors, direction filtering, burst confirmation and gap tolerance inside enabled regions. It is neither object tracking nor hardware motion vectors.

Optional CSV, transition JSONL and nonblocking FIFO output live in shared `logs/`, with one rotated copy after 5 MB. Detection can settle after servo/preset changes. Image processing includes normalized crop, 21 named software presets (some share algorithms) and small-translation stabilization with about 3% edge cropping. Optional burned-in captions and VU meters are excluded from the detector input. These features add CPU load and JPEG recompression.

## 录制、预设与归档 / Recording, presets and archives

“媒体 → 录制控制与抓拍”提供真正的立即手动录像、最长时长和停止操作；自动录像的暂停状态保持原值。“触发一次事件”用于外部触发，并遵守自动录像暂停。运动抓拍模式按设定间隔保存 JPEG。独立抓拍分辨率留空时仍保存当前预览帧；指定其他尺寸会关闭当前录像、临时释放相机抓拍，随后恢复预览。该尺寸必须由摄像头支持，实际可用性需要逐设备测试。

Media → Recording controls starts/stops immediate manual recording without changing the automatic pause setting. External triggers obey pause. Motion-photo mode saves JPEGs at the selected interval. Leaving the separate still size blank uses the current preview frame. A different size closes the active recording and temporarily releases the camera for capture, then restores preview. Supported sizes depend on the camera and require hardware validation.

文件名支持 `{kind}`、`{date}`、`{time}`、`{seq:06d}`、`{hostname}`。序号保存在共享 `.media-sequence`，使用文件锁，重启或回退版本后继续。名称只允许安全的单层文件名。“补建缺失缩略图”在后台从录像重建整帧缩略图，旧的目标裁剪缩略图因缺少原始框信息不自动重建。

Names support `{kind}`, `{date}`, `{time}`, `{seq:06d}` and `{hostname}` with a locked, persistent shared `.media-sequence`. Thumbnail repair runs in the background and recreates full-frame thumbnails; historical object crops without saved boxes cannot be reconstructed.

“系统 → 复制或移动配置预设”可操作整个预设或指定部分，如 `motion`。云台支持反相、步进、多步命令、位置巡航及每个位置绑定配置预设。GPIO 后端需要对应库及设备权限；无硬件时不会伪报移动成功。lgpio 为软件脉冲输出，精度取决于系统负载。

System → Copy/move presets supports a complete preset or a section such as `motion`. Servo controls add inversion, steps, multi-step commands, patrol and a settings preset bound to each position. GPIO backends require their libraries/device permissions. lgpio uses software pulses whose precision depends on system load.

归档目标可填写本地目录、由操作系统挂载的 NFS / SMB 目录，或原有 `user@host:/path` SSH 目标。本地归档保存为 `年/月/日/videos|stills|events`，校验 SHA-256 后才发布索引，保留原文件，并检查目标剩余空间；同名但内容不同会拒绝覆盖。SSH 使用 SCP 参数调用，不再拼接 shell 命令，远端空间与校验不作保证。需要开机自动挂载时使用操作系统的挂载配置，程序不接管 root 权限。日历面板按日期查询本地归档。

Archive to a local directory, OS-mounted NFS/SMB, or the existing `user@host:/path` SSH destination. Local archives use year/month/day folders, verify SHA-256 before publishing metadata, preserve originals, check free space and refuse different files at an existing name. SSH uses argument-based SCP; remote free space and checksums are not verified. Configure boot mounts in the OS. The calendar browses local archives by date.

## 定时、扩展与命令 / Schedules, extensions and commands

保存经纬度及 IANA 时区（例如 `Asia/Shanghai`）后，命令时间可填写 `dawn`、`sunrise`、`sunset`、`dusk`、`sunset-30` 等。晨昏为民用晨昏，时间按 [NOAA 近似公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF) 计算；极昼极夜没有对应时刻时不执行。固定间隔修复了跨午夜计时，网页条目不能伪造本地文件标记以执行 shell。

Set coordinates and an IANA time zone such as `Asia/Shanghai` to use `dawn`, `sunrise`, `sunset`, `dusk` or minute offsets like `sunset-30`. Civil twilight follows [NOAA approximate equations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF); unavailable polar events are skipped. Interval schedules work across midnight. Web entries cannot forge the trusted local shell marker.

新增钩子 / New hooks: `on_startup`, `on_motion_enable`, `on_loop_end`, `on_manual_end`, `on_still_capture`, `on_multicast_pkc_message`。多机消息通过 `PMC_MESSAGE`、`PMC_PEER` 环境变量传给本地钩子，不直接插入 shell。 / Multi-camera message payloads reach local hooks through `PMC_MESSAGE` and `PMC_PEER`, without direct shell interpolation.

```bash
python3 pimotioncam.py --version
python3 pimotioncam.py --config /path/config.json --check-config
python3 pimotioncam.py --command 'record start 60'
python3 pimotioncam.py --command 'record stop'
python3 pimotioncam.py --command 'motion trigger 2'
python3 pimotioncam.py --command 'audio record 120'
python3 pimotioncam.py --command 'audio record_stop'
python3 pimotioncam.py --command 'servo step pan 1 multi'
python3 pimotioncam.py --command 'servo scan on'
python3 pimotioncam.py --command 'servo scan off'
```

`record on/off` 保留启用 / 暂停自动录像的原有语义。还支持 `inform TEXT`、`annotate add/remove TEXT` 和 `display <|>|sel|back` 三项预览快捷菜单。外观面板提供深 / 浅 / 系统主题、HTTP(S) 扩展链接和日志行数；相机设置可以独立导入、导出。

`record on/off` retains automatic-recording enable/pause semantics. Other commands include `inform TEXT`, `annotate add/remove TEXT`, and a three-action preview menu via `display <|>|sel|back`. Appearance adds light/dark/system themes, HTTP(S) links and log length; camera settings can be imported/exported independently.

## 多机控制 / Multi-camera control

TCP / UDP 组播默认关闭。需要配置至少 16 字符共享密钥和允许的来源 IP。TCP 默认仅监听 `127.0.0.1:3000`；组播默认为 `225.0.0.55:22555`，TTL 1。消息用 HMAC-SHA256 签名，限制时间窗口、包大小、并发和重复 ID；响应包含签名 ACK。网络命令仅允许录制、检测、预设、延时和抓拍，不接受任意 shell、系统重启或钩子配置。这是 PiMotionCam 协议，不与上游未认证的原始网络格式兼容。

TCP/multicast is off by default and requires a shared secret of at least 16 characters plus allowed source IPs. TCP defaults to `127.0.0.1:3000`; multicast to `225.0.0.55:22555`, TTL 1. HMAC-SHA256, timestamps, bounded messages/concurrency, replay checks and signed ACKs protect a restricted command set. This is a PiMotionCam protocol; legacy unauthenticated packets are not accepted.

```bash
# 在调用终端安全设置 PMC_CONTROL_SECRET / Set PMC_CONTROL_SECRET in your shell.
python3 tools/control_client.py --tcp --host 127.0.0.1 --port 3000 'motion trigger 2'
python3 tools/control_client.py --host 225.0.0.55 --port 22555 --message 'Camera A: motion'
```
